01 / CONTEXTO

Introducción

Web Scanner es una aplicación de escritorio y CLI para revisar aspectos observables de la configuración de un sitio web. Analiza DNS, HTTP, cabeceras de seguridad y TLS; permite consultar un historial local y exportar informes. La interfaz Python utiliza PySide6. Existe además una interfaz nativa opcional en C++/Qt que se conecta al motor Python local.

Las comprobaciones son observacionales y de bajo impacto. La herramienta apoya una revisión técnica; no sustituye una auditoría completa.

02 / ALCANCE

Uso responsable

Utiliza la herramienta únicamente en sistemas propios o con autorización explícita. Respeta el alcance, los horarios y las condiciones acordadas. No la uses para evadir controles, interrumpir servicios ni obtener acceso no autorizado.

Un hallazgo es evidencia técnica para revisión y no confirma automáticamente una vulnerabilidad. Verifica cada observación de forma independiente antes de actuar. Consulta los Términos de uso.

03 / COMPROBACIONES

Módulos disponibles

DNS

Consulta información pública asociada al dominio objetivo.

HTTP

Observa respuestas HTTP, redirecciones e infraestructura visible.

Headers

Revisa cabeceras de seguridad presentes o ausentes en las respuestas comprobadas.

TLS

Resume datos observables del certificado y la conexión de transporte.

04 / APLICACIÓN DE ESCRITORIO

Uso de la interfaz

  1. Instala la aplicación desde la carpeta del proyecto según la guía de Descargas.
  2. Abre Web Scanner con web-scanner --gui.
  3. Introduce una URL autorizada y elige los módulos que forman parte de tu alcance.
  4. Inicia el análisis y revisa la evidencia, la confianza, el estado y las recomendaciones.
  5. Exporta el informe solo a una ubicación adecuada y protégelo como información sensible.

05 / TERMINAL

Ejecución desde la línea de comandos

Ejemplos de análisis de bajo impacto. Sustituye el objetivo solo por un sistema propio o expresamente autorizado:

Comandos de ejemplo

web-scanner https://example.com
web-scanner https://example.com --modules dns http headers tls
web-scanner https://example.com --output resultado.json
web-scanner https://example.com --pdf informe.pdf

06 / RESULTADOS

Exportar JSON

Añade --output y una ruta para guardar los datos estructurados del análisis en JSON. Por ejemplo: web-scanner https://example.com --output resultado.json. Conserva el archivo en un lugar privado; puede contener información del objetivo.

07 / INFORMES

Exportar PDF

Usa --pdf seguido de la ruta del documento para generar un informe. ReportLab es una dependencia opcional. Instálala desde la carpeta scanner del proyecto con python -m pip install -e ".[reports]".

08 / ASISTENCIA OPCIONAL

Resumen IA con Gemini u Ollama

La generación de resúmenes es opcional. Gemini necesita una clave API configurada en el entorno; Ollama puede funcionar localmente como alternativa cuando está instalado y disponible. En la CLI, la opción --ai-summary solicita un resumen y --ollama-model permite indicar el modelo local.

Considera la privacidad

No envíes información confidencial a servicios externos. Revisa la configuración y las condiciones del proveedor que uses. La IA redacta un resumen: no valida evidencias ni determina si un sistema es vulnerable.

09 / EVIDENCIA

Interpretación de resultados

Observed
La condición o respuesta descrita fue observada durante la comprobación. Es un registro técnico, no una confirmación automática de vulnerabilidad.
Missing
El elemento comprobado no apareció en la respuesta revisada. Su importancia depende del contexto y de la política de seguridad de la aplicación.
Confidence
Indicador cualitativo de confianza en la observación. No es una probabilidad ni sustituye la revisión.
Errores no concluyentes
Una conexión fallida, una respuesta incompleta o una comprobación interrumpida no demuestra que una configuración esté presente o ausente. Investiga el error antes de sacar conclusiones.

Todos los resultados son evidencia técnica para revisión. Ninguna observación confirma automáticamente una vulnerabilidad.

10 / AYUDA

Preguntas frecuentes

¿Se requiere una clave IA para ejecutar análisis?

No. La IA es opcional; las comprobaciones principales y la exportación JSON funcionan sin ella.

¿Cómo habilito informes PDF?

Instala el extra opcional ReportLab con python -m pip install -e ".[reports]" desde la carpeta del proyecto.

¿Qué debo hacer con un error de análisis?

Trátalo como no concluyente. Comprueba conectividad y alcance autorizado; no interpretes un error como una confirmación de seguridad o de riesgo.

¿Dónde encuentro instrucciones de instalación?

Consulta la página de Descargas y la guía de usuario incluida en el repositorio.
