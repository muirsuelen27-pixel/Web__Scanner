INSTALACIÓN DESDE EL CÓDIGO

Instalación con Python

Necesitas Python 3.10 o superior, Git para clonar el repositorio y acceso a la red para instalar dependencias.

  1. 01Instala Python 3.10 o superior.
  2. 02Clona o descarga el repositorio oficial.
  3. 03Abre la carpeta scanner, que contiene el proyecto instalable.
  4. 04Crea y activa un entorno virtual.
  5. 05Instala Web Scanner y sus dependencias.
  6. 06Inicia la interfaz con web-scanner --gui.

Windows PowerShell

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
web-scanner --gui

Linux y macOS

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
web-scanner --gui

Ubicación del proyecto

Ejecuta estos comandos desde la carpeta scanner del repositorio. En Windows, si PowerShell bloquea la activación del entorno, consulta las instrucciones de la documentación.

RESPUESTAS RÁPIDAS

Preguntas frecuentes

¿Necesito una clave de IA?

No. La IA es opcional. Gemini requiere configurar una clave; Ollama puede usarse localmente si está instalado y disponible.

¿Dónde se guardan los informes?

El historial se guarda localmente en .scanner/history; su ubicación depende del directorio de trabajo desde el que se inicia la aplicación. Los archivos exportados se guardan en la ruta que elijas.

¿Puedo analizar cualquier sitio?

No. Analiza únicamente sistemas propios o para los que tengas autorización explícita, y respeta el alcance acordado.

¿Cómo actualizo?

Si instalaste desde el repositorio, consulta las instrucciones en Actualizaciones. Las descargas binarias oficiales se anunciarán cuando estén disponibles.
