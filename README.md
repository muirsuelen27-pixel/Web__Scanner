# Web Scanner website

Official static website for the Web Scanner v2 beta. It is intended to be
published separately with GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a small local web server from this
directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing

Publish the contents of this repository from the `main` branch with GitHub
Pages. Keep the four product screenshots in `assets/images/` and avoid adding
private targets, reports, tokens, or customer data.
