MANTENIMIENTO

Actualizar desde código

Desde una copia clonada del repositorio, abre una terminal en la carpeta scanner. El comando git pull actualiza el repositorio y la instalación editable aplica los extras opcionales.

Terminal

git pull
python -m pip install -e ".[reports,dev]"
